# About this template

This template is powered by Jekyll and Bootstrap. It is deliberately sparse so you can adapt it for a new repository without carrying over old content.

Start by editing the site title, homepage text, and top navigation. Then add your own references, events, and curation notes.

You can add structured content later through `_data` files if needed, but the starter site keeps the public pages minimal.
